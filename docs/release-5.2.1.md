# إصدار الإضافة 5.2.1 — 16 سبتمبر 2026

إصدار تصحيحي لعرض رقم جديد بعد نشر تعديلَي #84 و#85. المصدر المعتمد لإصدار إضافة Stremio هو `src/release.js`، ويظهر الرقم نفسه في Manifest و`/health` والواجهة الرئيسية وأسماء خيارات الترجمة. معرّف الإضافة ثابت حتى لا تُعامل كتثبيت جديد.

- #84: تحسين البحث باسم ملف الفيديو الكامل عبر SubDL v2 مع الرجوع إلى البحث القديم، والتحقق من هوية الحلقة وروابط التنزيل.
- #85: منع ظهور معرفات النتائج التي قد تحمل مفاتيح مزوّد الترجمة في سجلات V5 باستبدالها بمعرفات مجزأة.

**لا يُعد هذا إصدارًا يؤكد حل المشكلة #82.** اختبار إنتاج 16 سبتمبر أعاد صفر نتائج `certified` وصفر `safe` لنسخ BluRay الثلاث المعروفة؛ البدائل من WEB ولا يوجد إثبات لتوافق توقيتها مع الفيديو. البلاغ مفتوح إلى حين ظهور دليل توقيت فعلي. يجب أيضًا تدوير مفتاح SubDL القديم من حساب المزود إذا كان قد ظهر في سجلات سابقة.

تنبيه: رقم إصدار حزمة npm الخاصة والموجود في `package.json` و`package-lock.json` ما زال 5.2.0؛ هذا الإصدار يغيّر رقم **إضافة Stremio المنشورة** فقط، ولا يغيّر حزمة npm أو شجرة اعتمادياتها. مطلوب توحيد بيانات الحزمة عند أول إصدار حزمة منفصل.
